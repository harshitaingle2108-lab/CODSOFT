# Currency Converter

## Description
A Java application that converts currency values between INR, USD, and EUR using predefined exchange rates.

## Features
- INR to USD conversion
- USD to INR conversion
- INR to EUR conversion
- EUR to INR conversion
- Menu-driven interface

## Technologies Used
- Java
- Scanner Class

## How to Run
1. Compile the program.
2. Run the CurrencyConverter class.
3. Select a conversion option.
4. Enter the amount.
5. View the converted value.
