# Number Game

## Description
A Java-based Number Guessing Game where the user tries to guess a randomly generated number within a limited number of attempts.

## Features
- Random number generation
- User input handling
- Limited attempts
- Too High / Too Low hints
- Play Again option

## Technologies Used
- Java
- Scanner Class
- Random Class

## How to Run
1. Compile the program.
2. Run the NumberGame class.
3. Enter your guesses.
4. Try to guess the correct number.
