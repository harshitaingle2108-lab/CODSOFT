# Student Grade Calculator

## Description
A Java application that calculates a student's total marks, percentage, grade, highest mark, and lowest mark.

## Features
- Accept marks for multiple subjects
- Calculate total marks
- Calculate percentage
- Assign grades
- Display highest and lowest marks
- Show Pass/Fail result

## Technologies Used
- Java
- Scanner Class

## How to Run
1. Compile the program.
2. Run the StudentGradeCalculator class.
3. Enter the number of subjects.
4. Enter marks for each subject.
5. View the result.
