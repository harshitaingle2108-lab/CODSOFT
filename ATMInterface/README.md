
# ATM Interface

## Description
A simple Java-based ATM simulation that allows users to check balance, deposit money, and withdraw money.

## Features
- Check account balance
- Deposit money
- Withdraw money
- Menu-driven interface
- Input validation

## Technologies Used
- Java
- Scanner Class

## How to Run
1. Compile the program.
2. Run the ATMInterface class.
3. Choose an option from the menu.
4. Perform banking operations.
