# CODSOFT Java Internship Projects

This repository contains my Java internship tasks completed as part of the CODSOFT Internship Program. The projects are developed using Core Java and demonstrate basic programming concepts, user input handling, conditional statements, loops, methods, and simple problem-solving techniques.

## Task 1: Number Game

### Description
A console-based number guessing game where the user tries to guess a randomly generated number.

### Features
- Random number generation
- User input using Scanner
- Multiple attempts
- Hints for higher or lower guesses
- Displays success message when guessed correctly

---

## Task 2: Student Grade Calculator

### Description
A Java program that accepts marks of multiple subjects and calculates the overall result.

### Features
- Accepts marks for multiple subjects
- Calculates total marks
- Calculates average percentage
- Finds highest and lowest marks
- Displays grade
- Displays Pass/Fail status

---

## Task 3: ATM Interface

### Description
A simple ATM simulation using Java with menu-driven operations.

### Features
- Check account balance
- Deposit money
- Withdraw money
- Input validation
- Menu-driven interface

---

## Task 4: Currency Converter

### Description
A console-based currency converter using predefined exchange rates.

### Features
- INR to USD conversion
- USD to INR conversion
- INR to EUR conversion
- EUR to INR conversion
- Menu-driven interface
